# Netflix Movie Data Analysis

## About the Project
This project analyzes Netflix movie data using Python
to identify trends related to genres, ratings, popularity and release years.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Analysis
- Most frequent movie genre
- Popularity distribution
- Most popular movies
- Movies released by year
- Genre-wise popularity

## Key Findings
- Drama was the most frequent genre in the dataset.
- Drama also showed high representation in popularity.
- Spider-Man: No Way Home was among the highly popular movies in the analysis.
- 2020 had the highest number of movies in the analyzed dataset.

## Project Structure
- Netflix_Movie_Analysis.ipynb — Complete analysis
- netflix_movies.csv — Dataset
- images/ — Analysis visualizations
